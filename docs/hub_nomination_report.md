# Stage D Hub-Nomination Report — Cross-species integration and machine-learning target locking for perioperative neurocognitive disorders (PND)

**Author:** Yongxin Yang · **Deposited:** 2026-10-05 · **Repository:** https://github.com/yyx-4113/pnd-sgk1-tcm-md (tag v1.1.1)

This report accompanies the manuscript *"SGK1 as a computational candidate target for perioperative neurocognitive disorders: in silico traditional Chinese medicine screening and 100 ns molecular dynamics pose-retention assessment"* and provides the upstream, target-nomination evidence that motivates SGK1 as the lead candidate. It is cited in the manuscript as Yang (2026).

## 1. Objective

Identify, from a cross-species computational pipeline, hub genes that are (a) consistently implicated across mouse hippocampal mechanism-level evidence and human directional/epigenomic signals, and (b) tractable for structure-based small-molecule intervention, so that one can be carried into docking and a molecular dynamics pose-retention assessment.

## 2. Pipeline (Stage D)

1. **Mouse hippocampal mechanism layer.** Differential expression (DEG) integration across available mouse hippocampal PND/POCD datasets; weighted gene co-expression network analysis (WGCNA) to recover co-expression modules; machine-learning target locking (LASSO / Boruta / random forest / XGBoost consensus) to rank candidate hub genes.
2. **Human directional-consistency layer.** Direction of effect in human PND/POCD transcriptomic and directional datasets, used as a consistency filter (not a significance test).
3. **Human epigenomic layer.** DNA-methylation (PND/POCD methylation arrays) screened for differentially methylated positions/loci.
4. **Cross-species consensus.** Genes surviving all three layers were taken forward as hub candidates.

## 3. Output — five hub genes

Five hub genes were nominated. SGK1 (serum/glucocorticoid-regulated kinase 1) was the **only** one with an experimentally resolved protein structure suitable for docking (PDB 7PUE, kinase domain, chain A, residues 82–376). The remaining four hubs would each require *de novo* AlphaFold modelling before any docking could be attempted and were therefore not pursued in the structure-based stage.

## 4. Limitations (disclosed, not hidden)

- **Mouse pseudoreplication / small samples.** The transcriptomic signal was inconsistent across independent mouse datasets; pseudoreplication and small per-group sample sizes limited confidence in the murine layer.
- **No human epigenomic signal.** The human methylation screen returned **no** FDR-significant differentially methylated locus; the epigenomic layer contributed directionality only.
- **Hypothesis, not proof.** These limits mean SGK1 is a *priority hypothesis* to be tested experimentally, not a demonstrated causal driver of PND. The docking/MD pose-retention assessment in the accompanying manuscript is independent computational corroboration of tractability, not confirmation of mechanism.

## 5. Provenance

The raw pipeline outputs (DEG tables, WGCNA module assignments, ML feature importance, directional-consistency tables, methylation screen) are generated by the project R pipeline (`PND_proj` scripts, Stages 00–10) and are available from the author on the project repository. This report is the citable summary of Stage D; it is intentionally a methods/results summary, not a peer-reviewed publication, and is deposited openly to satisfy the manuscript's data-availability and target-premise traceability requirements.
